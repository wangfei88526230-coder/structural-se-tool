儿童结构性SE估算 - 程序版本 2.0 / 算法冻结版 v1.0

使用：
1. 输入年龄（3-12岁）和性别。
2. 分别输入左右眼 AL(mm)、K1(D)、K2(D)。
3. 点击“计算”。

冻结算法：
Kmean=(K1+K2)/2
CR=337.5/Kmean
Rchild=AL/CR
ΔR=Rchild-Rref(age,sex)
ΔSE=beta(age)*ΔR
SEstruct=SEref(age)+ΔSE
